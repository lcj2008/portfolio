# 비트코인 자금세탁방지(AML) 이상거래 탐지

거래 간 자금 흐름을 학습하는 그래프 신경망(GCN)은 거래 특성을 이용하는 Random Forest(RF)보다 불법 거래를 더 잘 찾아낼 수 있을까? 3인 팀이 Elliptic 비트코인 거래 데이터로 두 모델을 재현하고, 클래스 불균형과 시간에 따른 거래 패턴 변화가 탐지 성능에 미치는 영향을 살펴봤습니다. 전체 거래 중 불법으로 표시된 비율은 약 2%였으며, 불법 거래 탐지의 정밀도와 재현율을 함께 보는 **Illicit F1**을 중심으로 비교했습니다.

## 이찬종의 역할

Python으로 RF와 GCN을 재현해 성능을 비교했습니다. GCN의 학습 과정에서 불법 거래의 오분류에 부여하는 가중치와 Focal Loss 설정을 바꿔 클래스 불균형을 다뤘습니다. 시간 특성을 추가한 GCN과 시점별로 가중치를 갱신하는 EvolveGCN을 비교하고, 성능이 떨어진 구간의 데이터 분포를 분석했습니다.

## 팀 실험 결과

GCN 구조와 학습 조건을 고정하고 손실함수 설정 6개를 각각 3개 시드로 반복했습니다. 아래는 그중 교차엔트로피의 클래스 가중치만 바꾼 세 조건입니다. [발표자료 10–12쪽](./기학심%20발표.pdf#page=10)

| 가중치 (합법, 불법) | 평균 Illicit F1 | 표준편차 |
|---|---:|---:|
| 0.5, 0.5 | 0.461 | 0.042 |
| 0.3, 0.7 | 0.610 | 0.028 |
| 0.2, 0.8 | **0.642** | 0.005 |

불법 거래의 가중치를 0.8로 높였을 때 평균 F1은 **0.181 상승**했습니다. 동일 가중치 조건을 기준으로 계산한 상대 개선율은 **약 39.3%**입니다. 실험한 Focal Loss 설정 중 이 값을 넘는 경우는 없었습니다.

별도로 집계한 최종 모델 비교표에서는 RF가 0.806으로 가장 높았습니다. 강한 가중치를 적용한 GCN은 0.644, EvolveGCN은 0.626, 시간 특성을 추가한 GCN은 0.586이었습니다. 43번째 시점에는 여러 모델의 성능이 함께 하락했습니다. 팀은 거래별 특성의 높은 중요도와 그래프의 낮은 연결성을 RF의 우세를 설명하는 단서로, 시점별 거래 분포 변화를 공통 하락의 가능한 원인으로 해석했습니다.
