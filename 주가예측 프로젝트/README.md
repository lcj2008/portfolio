# 뉴스·SNS 감성을 활용한 국내 방산주 주가 예측

한국어 뉴스와 투자 커뮤니티의 반응을 함께 보면 다음 거래일의 주가 방향을 더 잘 예측할 수 있을까? 팀은 국내 방산 기업 3곳을 대상으로 기술적 지표에 뉴스와 SNS 감성 점수를 하나씩 더해 방향 적중률(Hit Ratio)을 비교했습니다.

## 이찬종의 역할

팀 리더로 프로젝트를 기획하고 주가·뉴스·SNS 데이터 수집과 전처리를 담당했습니다. 한국어 금융 텍스트의 감성을 분석할 모델로 GPT-4o mini와 KR-FinBERT를 선정하고, 이동평균선 간 관계를 표현하는 정배열 지수·장기 이격도·이평선 수렴도 등의 파생변수를 설계했습니다. 팀이 비교한 XGBoost, CNN-LSTM, TCN 가운데 **TCN의 학습과 검증**을 맡았습니다.

## 데이터와 예측 과정

1. 뉴스 제목과 커뮤니티 게시글을 수집하고, 해당 기업의 주가에 긍정적·중립적·부정적인 내용인지 판정해 감성 지표를 구성했습니다.
2. Python으로 주가와 거래량, 기술적 지표, 감성 지표를 전처리했습니다. 거래량은 로그 변환하고 상관이 높은 기술 지표를 걸러냈습니다.
3. 최근 5거래일의 관측값으로 다음 거래일을 예측했습니다. TCN은 연속값인 주가 변동률을 학습했고, 프로젝트에서는 가격 방향을 얼마나 자주 맞혔는지도 평가했습니다. [발표 대본 2–4쪽](./뉴스%20및%20SNS%20데이터를%20활용한%20주가예측%20프로젝트_발표자료.pdf#page=2)

## 팀 실험 결과와 수상

| 입력 데이터 | 방향 적중률 |
|---|---:|
| 기술적 지표 | 49.67% |
| 기술적 지표 + 뉴스 | 48.69% |
| 기술적 지표 + SNS | 49.56% |
| 기술적 지표 + 뉴스 + SNS | **52.95%** |

뉴스와 SNS를 각각 추가한 조건은 기준선보다 낮았고, 두 자료를 함께 넣은 조건은 기준선보다 **3.28%p** 높았습니다. 이는 팀의 입력 조합 비교 결과입니다. 해당 그래프에는 사용 모델과 평가 분할이 명시되지 않아 TCN 단독 성능은 이 표에서 확인할 수 없습니다. [발표 슬라이드 15쪽](./뉴스%20및%20SNS%20데이터를%20활용한%20주가예측%20프로젝트_PPT.pdf#page=15)
