# Machine Unlearning 논문 분석

학습에 쓰인 샘플 하나를 삭제해 달라는 요청이 들어오면 모델은 어디서부터 다시 학습해야 할까? 2025년 2학기 비디오이미지프로세싱 과목에서 SISA 학습 구조를 조사하고, 삭제 요청 한 건이 영향을 미치는 학습 범위와 그에 따른 비용을 분석했습니다. 결과물은 분석 보고서와 2인 공동 발표자료입니다.

## 이찬종의 역할

관련 논문을 읽고 기존 방법의 한계를 비교했으며, SISA의 학습 과정과 논문에 보고된 실험 결과를 분석했습니다. 특히 삭제 후 다시 학습할 데이터가 줄어드는 과정과 그에 따른 정확도·저장 비용의 변화를 보고서로 정리하고 공동 발표에 참여했습니다. [분석 보고서](./Machine%20Unlearning_보고서_C111143%20이찬종.pdf) · [공동 발표자료](./Machine%20Unlearning_발표자료_C111143%20이찬종.pdf)

## 분석한 문제와 방법

원본 데이터를 지운 뒤에도 그 샘플이 학습 중 바꾼 파라미터는 모델에 남습니다. 남은 데이터 전체로 처음부터 재학습하면 삭제 요청마다 같은 작업이 반복됩니다. 보고서에서는 개별 샘플의 영향을 제한하는 차등 프라이버시, 삭제에 대한 보증을 제공하는 기법 등을 비교하고, 적용할 수 있는 모델과 보증 범위를 검토했습니다.

SISA는 학습할 때부터 각 샘플의 영향이 미치는 범위를 제한합니다.

| 구성 | 학습과 삭제에서 하는 일 |
|---|---|
| Sharding · Isolation | 데이터를 여러 묶음(shard)으로 나누고 묶음마다 별도 모델을 학습합니다. 한 샘플이 들어간 묶음을 알면 다시 학습할 모델을 특정할 수 있습니다. |
| Slicing | 각 묶음을 순차적으로 학습할 구간(slice)으로 나누고 중간 상태를 저장합니다. 삭제 시 해당 샘플을 제외하고 그 구간 직전의 체크포인트부터 다시 학습합니다. |
| Aggregation | 각 모델의 예측을 합쳐 최종 결과를 냅니다. 삭제 요청의 영향을 받지 않은 묶음의 모델은 계속 사용할 수 있습니다. |

## 논문 실험에서 읽어낸 결과

- **재학습 범위와 정확도.** 묶음을 늘리면 한 번의 삭제 요청으로 다시 학습할 데이터가 줄어듭니다. 논문의 단순 분류 과제에서는 정확도 손실이 작았지만, 복잡한 이미지 분류에서는 개별 모델이 학습할 데이터가 줄면서 정확도 하락이 커졌습니다.
- **재학습 시간과 저장 비용.** 구간별 체크포인트를 두면 삭제된 샘플을 학습하기 전까지의 계산을 재사용할 수 있습니다. 그만큼 중간 모델 상태를 저장할 공간이 필요하고, 삭제 요청이 여러 묶음에 걸치면 다시 학습할 범위도 넓어집니다.

이 프로젝트의 성과는 데이터 분할과 체크포인트 설정이 삭제 비용과 정확도에 미치는 영향을 논문 결과에 근거해 설명한 것입니다. 직접 실행한 재현 실험이나 자체 측정치는 미확인입니다. [보고서의 실험 결과 분석 2쪽](./Machine%20Unlearning_보고서_C111143%20이찬종.pdf#page=2)
